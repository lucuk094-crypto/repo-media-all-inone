## 🎯 LANGKAH DEPLOY KE VERCEL (5 MENIT)

### Step 1: Login ke Vercel
1. Buka browser
2. Go to: **https://vercel.com/dashboard**
3. Login dengan akun Anda

### Step 2: Import Project
1. Klik tombol **"Add New"** (pojok kanan atas)
2. Pilih **"Project"**
3. Klik **"Import Git Repository"**
4. Cari dan pilih: **`lucuk094-crypto/repo-media-all-inone`**
5. Klik **"Import"**

### Step 3: Configure Project
```
Framework Preset: Next.js (auto-detected) ✓
Root Directory: ./
Build Command: npm run build
Output Directory: .next
Install Command: npm install --legacy-peer-deps
Node.js Version: 18.x (recommended)
```

### Step 4: Environment Variables (Optional)
Jika ingin test demo mode:
```
Name: DEMO_MODE
Value: false
```
*Leave empty untuk production mode normal*

### Step 5: Deploy!
1. Klik tombol besar **"Deploy"** 🚀
2. Tunggu 2-3 menit
3. Vercel akan:
   - Install dependencies
   - Build project
   - Deploy to production
   - Generate URL

### Step 6: Get Your URL
Setelah selesai, Anda akan dapat URL seperti:
```
https://repo-media-all-inone.vercel.app
atau
https://repo-media-all-inone-lucuk094.vercel.app
```

**COPY URL INI!** ✅

## 💡 TIPS

### Jika Build Gagal di Vercel:
1. Check **Build Logs** di Vercel dashboard
2. Pastikan install command: `npm install --legacy-peer-deps`
3. Check Node.js version: Use 18.x

### Jika API Tidak Berfungsi:
1. Buka browser console (F12)
2. Check error messages
3. Verify URL format benar
4. Try different platform (to isolate issue)

### Custom Domain (Optional):
Setelah deploy sukses, Anda bisa:
1. Go to Project Settings → Domains
2. Add custom domain Anda
3. Configure DNS
4. SSL certificate auto-generated
